Instructions for cloning, setting up and building the project:
| Clone method | Download method |
|-----------------|----------------------|
| 1. Clone the project by running `git clone https://github.com/COS30031-rahul-tue-1430-g04/Assignment-2.git` | 1. Download the attached zip file.
| 2. Run `git checkout build-branch` | 2. Extract the Zip file |
3. Open Unity Hub and ensure you have version 6000.3.23f1 of the Unity Editor installed.
4. Click "Add" - "Add project from disk" and select the project you just cloned/downloaded
5. Open the project in Unity Editor 6000.3.23f1
6. Go to "File" - "Build profiles"
7. Switch to desired platform
8. Click "Build And Run" and choose a file location
